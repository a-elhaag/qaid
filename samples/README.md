# Sample receipts

Invented data only. `01.html` to `10.html` render the receipts listed in `ground-truth.json`.

1. Open each page, print it (or show it on a second screen).
2. Photograph it with a phone. Make one crumpled and one dim on purpose.
3. Save the photos as `samples/photos/01.jpg` ... `10.jpg` (git-ignored).
4. `npm run score` prints per-field accuracy. Set `FUSION=off` to score the Parse lane alone, then record the comparison in `docs/notes/extraction-score.md`.

Files 02, 06 and 08 use Arabic-Indic digits. File 10 shows a total only.
